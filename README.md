- CSS

- Express
- SQLite

## Installation

1. Installer Node.js 20 ou une version compatible.
2. Ouvrir un terminal dans le dossier du projet.
3. Installer les dépendances :

   npm install

4. Configurer le fichier .env.
5. Définir un SESSION_SECRET aléatoire et un mot de passe administrateur privé.
6. Lancer le serveur :

   npm start

7. Ouvrir dans le navigateur :

   http://localhost:3000
